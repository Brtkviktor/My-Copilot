# J.A.R.V.I.S Copilot Suite

> Uma suíte de prompts especializada para desenvolvimento de software com foco em Java, arquitetura limpa, aprendizado contínuo e engenharia de software moderna.

---

## 📖 Sobre o Projeto

O **J.A.R.V.I.S Copilot Suite** é um conjunto de prompts avançados para copilotos de IA inspirados no estilo do J.A.R.V.I.S..

A proposta é transformar a IA em um verdadeiro parceiro técnico, capaz de atuar em diferentes contextos de engenharia de software:

* estudo;
* planejamento;
* implementação;
* revisão;
* debugging;
* suporte técnico.

Cada modo possui:

* comportamento especializado;
* regras próprias;
* personalidade consistente;
* foco em qualidade;
* estrutura profissional.

---

# 🎯 Objetivos

Este projeto foi criado para:

* melhorar produtividade;
* fortalecer aprendizado em Java;
* acelerar evolução técnica;
* criar respostas mais consistentes;
* evitar respostas genéricas;
* aproximar a experiência de um copiloto real de engenharia.
